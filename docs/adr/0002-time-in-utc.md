# Время: API - в UTC, пояс владельца - константа спецификации

Слоты и встречи передаются по API мгновениями UTC в ISO 8601 (`2026-11-18T09:00:00Z`). У владельца один фиксированный пояс - Europe/Moscow, константа спецификации: в нём вычисляются рабочее время и окно записи, в нём же UI показывает время гостю. Представление времени врастает в сгенерированный SDK - менять его после контракта дорого всем клиентам сразу, поэтому решение зафиксировано до контракта (issue #1).

## Considered Options

- Показывать время в поясе гостя - отказ: демо-проект с одним владельцем получает неоднозначность «который час» без реальной пользы.
- Передавать локальное время без пояса - отказ: строка без пояса неоднозначна при любых конвертациях.
