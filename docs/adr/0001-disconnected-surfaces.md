# Две несвязанные поверхности: гость в корне, панель владельца - по прямому URL

Приложение состоит из двух поверхностей: публичная страница в корне `/` (гость) и панель владельца на `/admin` (инструменты). Переходов между ними нет ни в одну сторону: гость не видит пути к инструментам, владелец попадает в панель прямым URL. Отсутствие ссылки - не забытая деталь, а решение: его не надо «починить», добавив ссылку. Спецификация поверхностей - issue #3.

## Considered Options

- Незаметные ссылки в обе стороны (с публичной страницы - «Управление», с панели - «Публичная страница») - отклонено: публичная страница говорит только с гостем.
- Кабинет владельца в корне, как в Cal.com, публичная страница на отдельном маршруте - отклонено: первый экран оказался бы пустой админ-панелью до создания типов встреч.
