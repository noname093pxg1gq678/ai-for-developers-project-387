# Критерии ревью календаря

Эти критерии - источник замечаний для авторевью PR (`.github/workflows/pr-review.yml`) и ревьюера-человека. Замечания ищутся в diff PR по дефектам логики календаря; форматирование кода не ревьюится - это работа линтера (`oxfmt`).

## Занятый слот

- Занятый слот не остаётся доступным для повторной записи: после успешной записи слот исключается из доступных, повторная запись на то же время невозможна.

## Встреча вплотную

- Встреча вплотную разрешена: окончание одной встречи, совпадающее с началом следующей, - не пересечение, запись допустима.

## Пересечения

- Пересечения запрещены: новая запись не должна накладываться на существующую встречу ни по типам встреч, ни по длительности (сдвиги границ, частичные наложения, запись внутрь чужой встречи).

## Формат замечания

- Каждое замечание содержит: файл, строку, условия ошибки и последствие (что сломается).
- Если подтверждённых дефектов нет - ревью прямо об этом сообщает, замечания не выдумываются.
