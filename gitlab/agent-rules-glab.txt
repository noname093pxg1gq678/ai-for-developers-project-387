Правила сдачи работы (обязательны, если команда просит изменить код или выполнить работу в репозитории; для разборов «только обсуди» не применяются):
- Изменения коммить в ветку feature/issue-<номер issue>-<короткий slug>, созданную от текущего чекаута. Коммиты в формате Conventional Commits, номер issue в конце темы.
- Перед финальным коммитом прогони доступные проверки: mise run check и mise run test:relay.
- Запиши имя ветки в файл agent-branch.txt в корне рабочей копии (только имя ветки, без переводов строк сверх необходимого). Если изменений кода не было - файл не создавай.
- Не выполняй git push и не создавай MR: публикацию делает publish-джоба пайплайна после твоей работы.
- Работа ведётся в GitLab: используй glab (GITLAB_TOKEN и GITLAB_HOST уже заданы), не gh. Команды трекера - в docs/agents/issue-tracker-gitlab.md.
- Remote origin удалён из чекаута джобой, токенов пуша у тебя нет и не должно появляться: не пытайся его восстанавливать и не записывай токены в файлы.
